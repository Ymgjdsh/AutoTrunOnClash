# 公开内容与脱敏范围

本仓库发布 0.2.4 的主要源码、资源、测试、构建脚本及通用技术文档。应用与测试代码保留原有功能；应用包名、标准 Android / Clash 组件名和公开依赖地址属于构建所需信息，不替换为不可运行的占位值。

公开内容不包含：

- 个人设备型号、完整固件标识、真实运行日志、会话标识、实际应用 UID 或个人所选应用名单。
- 原始用户反馈、排障附件、设备截图和包含个人环境的历史验证报告。
- 开发者姓名、个人邮箱、本机用户名、绝对 SDK / JDK / 工作目录路径。
- local.properties、私有配置、令牌、订阅链接、账号密码、签名密钥或认证信息。
- 构建缓存、中间产物、APK、原始第三方源码下载缓存及本地工具文件。

.gitignore 排除上述常见本地产物，文档中的构建步骤使用环境变量或参数指定开发者自己的路径。Gradle Wrapper 和仅编译的 Xposed API JAR 为构建依赖，来源见对应说明，未包含个人签名文件。

运行时设置仍在应用私有存储中，诊断记录仅保存在内存；复制诊断会包含设备和应用使用信息，分享前仍需检查。此说明描述本次公开源码的整理范围，不代表任意未来提交或用户自行提供的诊断都已自动脱敏。
